# Windsurf

**Windsurf 是一款 AI 代码编辑器**，原由 Codeium 开发，免费档就提供不限量的 Tab 补全和行内编辑，付费档可使用前沿模型和云端 Agent。

## 主要功能

- Agent 编码，自主完成多步骤任务
- 不限量的 Tab 补全与行内编辑（含免费档）
- 可使用 OpenAI、Claude、Gemini 等模型（付费档）
- 云端 Agent（Devin Cloud）、Devin Bots
- 多人协作会话（团队版）

## 适合谁用

- 想先免费体验 AI 编辑器的个人开发者
- 需要云端 Agent 的团队

## 价格与免费额度

> 以下信息核实于 2026-11-22，以官网为准，价格可能随时调整。

- 官网显示：Free $0（轻量 Agent 额度，模型有限，Tab 补全和行内编辑不限量）
- Pro $20/月；更高档 $200/月；Teams $80/月（最多 100 名成员共享额度）；企业版定制
- 付费档额度按日和按周自动刷新，可按 API 价格购买额外用量

## 国内能否直接使用

国内网络下的访问与下载情况未核实（建议发布前实测）。付费需外币支付方式。

## 优缺点

**优点**

- 免费档补全不限量，入门成本低
- 支持多家模型
- 提供云端 Agent

**缺点**

- 产品与品牌近年变动较多（Codeium → Windsurf → 与 Devin 整合），后续路线存在不确定性
- 额度按日/周刷新，重度使用需关注上限

## 常见问题

### Windsurf 免费版能用什么？

可以无限使用 Tab 补全和行内编辑，Agent 只有少量额度，可用模型有限。

### Windsurf 和 Codeium 是什么关系？

Windsurf 编辑器最早由 Codeium 团队推出，目前官网已与 Devin 产品整合。

### Windsurf 和 Cursor 哪个好？

两者功能接近。Windsurf 免费档补全不限量，Cursor 的 Agent 生态更成熟，建议都试用后选择。

# CodeGeeX

**CodeGeeX 是智谱 AI 推出的免费 AI 编程插件**，可在 VS Code、JetBrains、HBuilderX 中使用，模型 CodeGeeX4-ALL-9B 已在 GitHub 开源。

## 主要功能

- 代码补全与行内对话
- 代码审查、单元测试生成
- 基于代码仓库的问答
- 开源模型可私有化部署

## 适合谁用

- 想免费使用 AI 编程插件的个人开发者
- 需要在内网私有部署代码模型的企业
- 使用 HBuilderX 的前端/uni-app 开发者

## 价格与免费额度

## 常见问题

### CodeGeeX 收费吗？

个人开发者免费，企业私有化部署需要单独询价。

### CodeGeeX 模型开源吗？

CodeGeeX4-ALL-9B 模型在 GitHub 开源，可以自行部署。

### CodeGeeX 支持哪些 IDE？

VS Code、JetBrains 系列（IntelliJ、PyCharm、WebStorm 等）和 HBuilderX。

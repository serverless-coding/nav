# GitHub Copilot

**GitHub Copilot 是 GitHub 官方的 AI 编程助手**，以插件形式运行在多种主流 IDE 中，并与 GitHub 的 Issue、PR 流程深度集成。

## 主要功能

- 代码补全与对话
- Agent 模式：在 VS Code、Visual Studio、JetBrains、Eclipse、Xcode 中自主完成任务
- 把 Issue 分配给 Copilot，自动生成 Pull Request
- PR 审查与文件 diff 审查
- 支持 MCP 服务器、自定义指令（instructions.md）
- Copilot CLI

## 适合谁用

- 已在使用 GitHub 托管代码的个人与团队
- 使用 JetBrains、Visual Studio、Xcode 等非 VS Code 编辑器的开发者
- 学生与开源维护者（GitHub 提供相关优惠，具体资格未核实（建议发布前实测））

## 价格与免费额度

> 以下信息核实于 2026-11-22，以官网为准，价格可能随时调整。

- 官网显示：Free $0（有限的对话与 Agent 用量）
- Pro $10/月；Pro+ $39/月；Max $100/月（按用户计）
- 各档位附带 GitHub AI Credits，Agent、代码审查、云端 Copilot 等功能会消耗额度，可额外购买

## 国内能否直接使用

github.com 在国内通常可以访问，但速度和稳定性因网络而异；Copilot 服务在国内的稳定性未核实（建议发布前实测）。付费需要支持外币的银行卡或 PayPal。

## 优缺点

**优点**

- 支持的 IDE 最多
- 与 GitHub 工作流结合紧密
- 有免费档，入门门槛低

**缺点**

- 额度计费（AI Credits）规则较复杂
- 国内网络下可能出现连接不稳定

## 常见问题

### GitHub Copilot 有免费版吗？

有。免费档提供有限的对话和 Agent 用量。

### Copilot 支持哪些编辑器？

官网列出 VS Code、Visual Studio、Xcode、JetBrains 全家桶、Neovim、Raycast、SQL Server Management Studio 等。

### Copilot 能自动提交 PR 吗？

可以把 Issue 分配给 Copilot，它会编写代码并创建 Pull Request，再由人工审查合并。

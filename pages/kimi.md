# Kimi

**Kimi 是月之暗面推出的 AI 助手**，从长文本阅读起家，现已扩展到深度研究、文档与 PPT 生成、网站制作和多 Agent 任务。

## 主要功能

- 长文本与文件阅读、总结
- Deep Research 深度研究
- 文档、演示文稿生成与网站部署
- Kimi Code 编程（Plus 及以上会员）
- Agent Swarm 多智能体任务、定时任务（高档会员）

## 适合谁用

- 需要读长文档、做资料调研的学生和研究者
- 希望 AI 直接产出文档、PPT、网页的办公用户
- 需要编程助手的开发者（选 Plus 及以上）

## 价格与免费额度

> 以下信息核实于 2026-11-22，以官网为准，价格可能随时调整。

- 免费版：可使用，高峰期可能排队（具体额度未核实）
- 会员（官方帮助中心，采集于 2026-10-19）：Go ¥49/月（年付 ¥468）、Plus ¥99/月（年付 ¥948）、Pro ¥199/月（年付 ¥1,908）、Max ¥699/月（年付 ¥6,708）、Ultra ¥1,399/月（年付 ¥13,428）
- Go 档不含 Kimi Code，需 Plus 及以上
- 旧版 Andante / Moderato / Allegretto / Allegro 套餐的老用户可继续保留原权益

## 支持平台与国内使用

- 网页版与 App 可用（桌面客户端未核实）
- 国内可直接访问

## 优缺点

**优点**

- 长文本和资料研究能力强
- 模型以开放权重形式发布，有 API 可用

**缺点**

- 会员档位多，编程功能门槛从 Go 提高到 Plus
- 2026 年 7 月曾因算力紧张暂停新会员订阅，服务稳定性受算力影响

### Kimi 免费吗？

有免费版，深度功能和更多额度需要会员。

### Kimi 会员多少钱？

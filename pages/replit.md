# Replit

**Replit 是一个浏览器内的在线开发与部署平台**，通过 Replit Agent 可以用自然语言生成完整应用。

## 主要功能

- 在线 IDE，支持多种语言
- Replit Agent：用自然语言构建应用
- 一键部署与托管
- 数据库及回滚（高档位）
- 多人协作

## 适合谁用

- 编程初学者和教学场景
- 需要快速搭建原型的个人开发者
- 想免去部署运维的小团队

## 价格与免费额度

> 以下信息核实于 2026-11-22，以官网为准，价格可能随时调整。

- 官网显示：Core $20/月（年付 $18/月），含 $20 的更强模型额度
- Pro $100/月（年付 $90/月），含 $100 模型额度、最多 15 名协作者、28 天数据库回滚等
- 提供按用量付费（Effort-Based Pricing）；是否有免费档未核实（建议发布前实测）

## 国内能否直接使用

国内网络下访问速度与稳定性未核实（建议发布前实测）。付费需外币支付方式。

## 优缺点

**优点**

- 开发、运行、部署全在浏览器完成
- Agent 适合快速出原型

**缺点**

- 按用量计费，成本需要关注
- 国内访问可能不稳定

## 常见问题

### Replit 多少钱？

Core 月付 $20，Pro 月付 $100，年付有折扣，另有按用量付费。

### Replit Agent 会出错吗？

官网说明 Agent 由大模型驱动，结果具有概率性，可能出错，需要人工检查。

### Replit 适合学编程吗？

适合，无需本地安装环境，打开浏览器即可写代码运行。

# 心流

**心流是阿里旗下团队推出的 AI 搜索与知识助手**，覆盖日常问答、学术论文阅读和内容创作，并提供开发者平台和命令行工具。

## 主要功能

- AI 搜索与问答，可解读学术论文
- 浏览器侧边栏插件：随时提问、总结网页
- 心流开放平台：提供兼容 OpenAI 格式的 API，可接入 Cline、沉浸式翻译等工具
- iFlow CLI：开源的终端 AI Agent 工具

## 适合谁用

- 需要读论文、查资料的学生和研究人员
- 想用免费模型配合 CLI 或编码插件的开发者

## 价格与免费额度

> 核实于 2026-11-22。

C 端产品的付费情况**未核实**。2025 年 8 月有技术社区文章称 iFlow CLI 可免费使用 Qwen3-Coder、Kimi K2 等模型，当前政策未核实。

## 支持平台与国内使用

网页（iflow.cn）、Chrome 插件、开放平台 API、iFlow CLI。国内可直接使用。

## 优缺点

**优点**：既有面向普通用户的助手，也有面向开发者的 API 和 CLI。

**缺点**：产品形态多，C 端和开发者产品入口容易混淆；收费规则未公开核实。

## 常见问题

### 心流是阿里的产品吗？
据第三方资料，由阿里旗下杭州万象创意科技开发；技术社区也称其为阿里心流团队。

### 心流 API 兼容 OpenAI 吗？
开放平台文档称接口与 OpenAI 兼容。

### iFlow CLI 是什么？
心流团队开源的终端 AI Agent 工具，类似 Claude Code。
